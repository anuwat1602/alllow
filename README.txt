ระบบคุมวัสดุ — วิธีติดตั้งและใช้งาน
====================================

ระบบนี้ใช้งานบนเครื่องคอมพิวเตอร์เครื่องเดียว ไม่ต้องติดตั้งโปรแกรม ไม่ต้องใช้อินเทอร์เน็ต
เปิดด้วย Google Chrome หรือ Microsoft Edge

ในโฟลเดอร์นี้มี
  KumWatsadu.html   ไฟล์ระบบ
  CreateIcon.vbs    ตัวช่วยสร้างไอคอนสำหรับเปิดระบบ
  icon.ico          รูปไอคอนของระบบ
  sample-data.json  ข้อมูลตัวอย่างสำหรับลองใช้
  README.txt        ไฟล์นี้

-------------------------------------------------
1) ติดตั้ง
-------------------------------------------------
1. คัดลอกโฟลเดอร์นี้ทั้งโฟลเดอร์ไปไว้ในเครื่อง เช่น D:\ระบบคุมวัสดุ
   (อย่าเปิดจากไฟล์ zip หรือแฟลชไดรฟ์โดยตรง)
2. ดับเบิลคลิก CreateIcon.vbs
   - จะได้ไอคอน "ระบบคุมวัสดุ" ในโฟลเดอร์นี้
   - ระบบจะถามว่าสร้างบนหน้าจอ (Desktop) ด้วยไหม กด Yes ถ้าต้องการ
   - ถ้า Windows ขึ้นคำเตือน ให้กด "เปิด" หรือ "Run"
3. ดับเบิลคลิกไอคอน "ระบบคุมวัสดุ" เพื่อเปิดระบบ
   (หรือดับเบิลคลิก KumWatsadu.html โดยตรงก็ได้)

-------------------------------------------------
2) ตั้งค่าครั้งแรก
-------------------------------------------------
ไปที่แท็บ "ตั้งค่า / สำรองข้อมูล"
  - กรอก กอง / งาน / ชื่อหน่วยงาน (ใช้เป็นหัวเว็บ หัวใบเบิก หัวรายงาน)
  - กรอกชื่อและตำแหน่งผู้อนุมัติ ผู้จ่ายของ
  - เลือกสีของระบบ และใส่โลโก้หน่วยงานได้
  - กด "บันทึกการตั้งค่า"

อยากลองดูก่อน: ที่แท็บเดียวกัน กด "เลือกไฟล์สำรองเพื่อกู้คืน..." เลือก sample-data.json
แล้วกด "กู้คืนข้อมูล" จะได้วัสดุและใบรับ-ใบเบิกตัวอย่าง
ลองเสร็จแล้ว กด "ล้างข้อมูลทั้งหมด" ที่แท็บเดียวกัน (กด 2 ครั้ง) เพื่อเริ่มใช้งานจริง

-------------------------------------------------
3) ลำดับการใช้งาน
-------------------------------------------------
  1. ทะเบียนวัสดุ  เพิ่มรายการวัสดุ (ชื่อ ประเภท หน่วยนับ)
  2. รับเข้า       บันทึกยอดยกมา (เลือกที่มา "ยอดยกมา") และการรับจากการจัดซื้อ
  3. ใบเบิกวัสดุ   ออกใบเบิก ตัดยอดคงเหลืออัตโนมัติ กด "พิมพ์" ได้ทันที
  4. วัสดุคงคลัง   ดูแดชบอร์ด ยอดคงเหลือ มูลค่า วัสดุที่หมด
  5. รายงาน       สรุปรับ-จ่าย-คงเหลือ รายเดือน/ปีงบ และบัญชีวัสดุรายตัว
                  พิมพ์ได้ และส่งออก Excel ได้

-------------------------------------------------
4) สำคัญ: การสำรองข้อมูล
-------------------------------------------------
ข้อมูลเก็บอยู่ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น
ถ้าลง Windows ใหม่ ล้างประวัติเบราว์เซอร์ หรือเปลี่ยนเครื่อง ข้อมูลจะหาย
  - กด "ดาวน์โหลดไฟล์สำรอง" ที่แท็บตั้งค่า อย่างน้อยเดือนละครั้ง
  - เก็บไฟล์สำรองไว้นอกเครื่อง เช่น แฟลชไดรฟ์ หรือไดรฟ์ออนไลน์
  - ย้ายเครื่อง: ติดตั้งโฟลเดอร์นี้ที่เครื่องใหม่ แล้วใช้ "กู้คืนข้อมูล" จากไฟล์สำรอง
  - ใช้เบราว์เซอร์เดิมทุกครั้ง (ไอคอนจะเปิดด้วย Chrome ให้อัตโนมัติถ้ามี)

-------------------------------------------------
5) ย้ายโฟลเดอร์
-------------------------------------------------
ถ้าย้ายโฟลเดอร์ไปที่อื่น ให้ดับเบิลคลิก CreateIcon.vbs ใหม่อีกครั้ง
ไอคอนจะได้ชี้ไปที่ไฟล์ระบบในที่ใหม่
